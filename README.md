# 本地托管：

- 使用 "Visual Studio Code" 应用程序

- 安装依赖：
pip install -r requirements.txt

- 配置 ".py" 文件中的 Token
（如有需要，也可填写你的 API 密钥以及 Discord 和 API 参数）

- 启动机器人：
python "机器人名称".py

⚠️ 如果出现错误消息，请前往我们的 <a href="https://chatgpt.com/">机器人技术支持</a> 😁😁
