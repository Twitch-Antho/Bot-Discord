# Héberger en Local :

- Use the application "Visual Studio Code"

- Install the dependencies:

- pip install -r requirements.txt

- Configure the ".py" file with your Token
( and your API application keys if needed for the bot )
Fill in your Discord and API settings.

- Run the bot:
python "bot name".py

⚠️ If you get an error message, please visit our <a href="https://chatgpt.com/">Bot Technician</a> 😁😁
