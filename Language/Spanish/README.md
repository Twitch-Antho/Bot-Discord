# Alojar en local :

* Utiliza la aplicación "Visual Studio Code"

* Instala las dependencias:

```
pip install -r requirements.txt
```

* Configura el archivo ".py" con tu Token
  ( y las claves de tus aplicaciones "API" si el bot las necesita )
  Completa tus parámetros de Discord y API.

* Ejecuta el bot:

```
python "nombre del bot".py
```

⚠️ Si aparece un mensaje de error, por favor visita nuestro <a href="https://chatgpt.com/">Técnico para bots</a> 😁😁

# ¿Token del Bot?

Para añadir tu Token debes ir al sitio de desarrolladores [Devellopeur](https://discord.com/developers) :

* Inicia sesión

* Ve a la categoría "Application" y crea una aplicación "Bot"

* Luego podrás configurar tu bot (elegir qué debe hacer) y darle permisos

* En la categoría **Bot** podrás reiniciar tu Token y copiarlo/pegarlo en el código
